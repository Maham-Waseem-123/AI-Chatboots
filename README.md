# 🌀 Chrono Heist - The Time Loop Puzzle

A mind-bending heist game where you coordinate with clones of yourself through time loops to pull off the ultimate vault robbery!

## 🎮 How to Play

1. Open `index.html` in any modern web browser
2. Click "BEGIN HEIST" to start your time loop adventure
3. Use the controls to navigate and interact with the vault

## 🕹️ Controls

- **WASD** or **Arrow Keys**: Move your character
- **E**: Interact with objects (collect items, hack terminals)
- **Space**: Use tools/special actions
- **Shift**: Enter stealth mode (slower but harder to detect)
- **R**: Manually reset the time loop (starts a new loop early)

## 🌀 Core Game Mechanics

### Time Loop System
- Each loop lasts **90 seconds**
- When time runs out, you automatically start a new loop
- Your previous actions are recorded and replayed by a **clone**
- Each new loop adds another clone following your past movements

### Game Phases

#### 🟡 Phase 1: Planning (Loop 1)
- Explore the vault layout
- Learn guard patrol patterns
- Collect basic items
- Disable simple security measures
- **Goal**: Gather intelligence for future loops

#### 🟠 Phase 2: Action (Loops 2-3)
- Coordinate with your clones
- Access areas requiring multiple people
- Complete complex objectives
- **Goal**: Use teamwork with past selves

#### 🔴 Phase 3: Extraction (Loop 4+)
- Execute the final heist plan
- Complete all objectives
- Reach the extraction point
- **Goal**: Pull off the perfect crime

### Adaptive AI Security
- **Guards** learn from your patterns and adapt their routes
- **Cameras** become more vigilant with each loop
- **Lasers** change patterns based on your behavior
- The security system gets smarter the more loops you complete!

## 🎯 Objectives

### Primary Objectives (Must Complete All):

1. **Hack Terminal** (Green)
   - Requires: Keycard
   - Unlocks basic security doors

2. **Disable Laser Grid** (Pink)
   - Requires: 1 Clone to assist
   - Disables laser security barriers

3. **Access Final Vault** (Purple)
   - Requires: Access Code + 2 Clones
   - The ultimate objective

### Collectibles:
- **🟡 Keycard**: Opens keycard-locked doors
- **🔵 Data**: Intelligence information
- **🟣 Code**: Required for final vault access
- **🟨 Treasure**: Bonus objective (stays collected across loops)

## 🎨 Visual Guide

- **🟢 Green Character**: You (current loop)
- **🔵 Blue Characters**: Your clones from previous loops
- **🟡 Yellow Guards**: Security patrol (orange when alerted)
- **🔴 Red Lasers**: Security barriers
- **🟨 Yellow Cones**: Camera vision areas
- **Stealth Mode**: Characters turn blue when in stealth

## 🧠 Strategy Tips

1. **Plan Your First Loop**: Use it to scout and learn patterns
2. **Clone Coordination**: Position clones to distract guards or hold doors
3. **Stealth Timing**: Use stealth mode to avoid detection when needed
4. **Adaptation Awareness**: Security gets harder each loop - stay unpredictable
5. **Tool Usage**: Save complex tool usage for when you have clone support

## 🏆 Victory Condition

Win by:
1. Completing all three primary objectives
2. Reaching the extraction point (top-right corner)
3. Doing it before the security AI becomes too adaptive to handle!

## 🎯 Scoring

Your score is based on:
- **Speed**: Fewer loops = better score
- **Stealth**: Avoiding detection bonuses
- **Efficiency**: Completing objectives quickly

## 🔧 Technical Features

- **Real-time clone recording and playback**
- **Adaptive AI that learns from player behavior**
- **Dynamic security system**
- **Multi-phase gameplay progression**
- **Responsive HTML5 Canvas graphics**
- **Cross-browser compatibility**

## 🎮 Game Design Philosophy

Chrono Heist combines puzzle-solving with action gameplay, where the core mechanic of time loops creates emergent strategies. Players must think several moves ahead, considering how their current actions will affect future loops and how their clones can be positioned to create opportunities.

The adaptive AI ensures that no single strategy works forever, encouraging creative problem-solving and experimentation across multiple playthroughs.
